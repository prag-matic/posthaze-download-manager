# Research: `misterdownloadmanager` Quality-of-Life (QOL) & UX Improvements for Posthaze

> **Scope:** Primary-source UX and Quality-of-Life (QOL) comparison between `misterdownloadmanager` (`mdm-app`, `mdm-engine`, `mdm-extract`, `mdm-nmhost`, browser extension) and Posthaze Download Manager (`posthaze-ui`, `posthaze-engine`, `posthaze-cli`, `extensions/chrome`), focused on **link intake & batching**, **post-download & file management**, **active transfer & OS integration**, and **browser extension UX**.
> **Exclusions:** Low-level engine connection handling, worker orchestration, and disk/throughput mechanics (already covered in [misterdownloadmanager-engine-comparison.md](file:///e:/Development/posthaze-download-manager/docs/research/misterdownloadmanager-engine-comparison.md)) and out-of-scope protocol/media integrations (BitTorrent, Debrid services, yt-dlp/gallery-dl).
> **Non-goal:** No application source code (`crates/`, `extensions/`, `Cargo.toml`) is modified by this document. Every factual claim cites exact file paths and line ranges directly inspected in both repositories.

---

## 1. Executive Summary & Prioritized QOL Matrix

Posthaze already has a notably clean, responsive desktop core (Pre-Flight window, Bash/`cmd` `cURL` parsing, outbound OS file drag-and-drop, multi-select toolbar, live filter/sort, BLAKE3 integrity, disk/FAT32 preflight, EcoQoS when hidden & idle, and 1-click Chromium Native Messaging setup). However, `misterdownloadmanager` (`mdm-app` / `mdm-engine` / `mdm-extract`) ships a large set of **daily-driver QOL safeguards and ergonomics** that eliminate common Windows friction—computers sleeping mid-download, expired signed links forcing a full restart from byte 0, silent permanent deletions instead of Recycle Bin, unreadable raw HTTP errors, and single-URL-at-a-time intake.

## 3. Deep Dive: Link Intake, Batching & Browser Extension UX

### 3.1 Duplicate URL Detection & Recent Save Folders History (`P0`)

- **Observed Gap in Posthaze:**
  - `resolve_target_path()` ([crates/posthaze-engine/src/model.rs#L690-L715](file:///e:/Development/posthaze-download-manager/crates/posthaze-engine/src/model.rs#L690-L715)) checks whether the *output filename* collides on disk, but neither `DownloadEngine` nor `PreflightWindow` checks whether the *URL* is already in SQLite (`Active`, `Queued`, `Paused`, or `Completed`). Re-clicking a link in the browser or pasting the same URL silently creates duplicate queue entries (`file (1).zip`, `file (2).zip`).
  - `PreflightWindow::apply_probe_info()` ([crates/posthaze-ui/src/preflight_window.rs#L215-L232](file:///e:/Development/posthaze-download-manager/crates/posthaze-ui/src/preflight_window.rs#L215-L232)) always pre-fills `dir_input` with `default_output_dir` (or categorized subfolder) with no memory of recently used save folders.
- **`misterdownloadmanager` Pattern:**
  - **URL Duplicate Policy:** `duplicate_step()` ([crates/app/src/app.rs#L87-L98](file:///C:/Users/prage/.gemini/antigravity/brain/68f916d5-a49d-44b1-b60f-1a921a1da2d5/scratch/misterdownloadmanager/crates/app/src/app.rs#L87-L98)) and `dialogs::Duplicate` ([crates/app/src/dialogs.rs#L4010-L4138](file:///C:/Users/prage/.gemini/antigravity/brain/68f916d5-a49d-44b1-b60f-1a921a1da2d5/scratch/misterdownloadmanager/crates/app/src/dialogs.rs#L4010-L4138)) detect matching URLs already in the queue and offer three clear choices: **(1) Add with numbered filename**, **(2) Replace / Overwrite existing**, or **(3) Open / Resume the existing entry** (and if the existing completed file was deleted from disk, `GoneLook` / `finished_file_gone` replaces the stale row cleanly).
  - **Recent Folder History:** `Settings::folder_history` ([crates/app/src/settings.rs#L368](file:///C:/Users/prage/.gemini/antigravity/brain/68f916d5-a49d-44b1-b60f-1a921a1da2d5/scratch/misterdownloadmanager/crates/app/src/settings.rs#L368)) records destination directories whenever a download is confirmed ([crates/app/src/app.rs#L13520-L13529](file:///C:/Users/prage/.gemini/antigravity/brain/68f916d5-a49d-44b1-b60f-1a921a1da2d5/scratch/misterdownloadmanager/crates/app/src/app.rs#L13520-L13529)) and feeds them into Save As (`app.rs#L11500`).
- **Posthaze Recommendation:**
  - In `PreflightWindow` (and `DownloadStore`), query for an existing record matching `original_url` or `final_url` and show a compact inline banner (`"Already in queue (Completed / Paused) — [Resume / Reveal] or Download Copy"`).
  - Persist the last ~8–10 chosen `output_dir` paths in SQLite and render them as clickable quick-select chips or a dropdown under `dir_input` in `PreflightWindow` and the `Move To...` modal.

### 3.2 Batch / Wildcard URL Expansion & Multi-Link Clipboard Import (`P1`)

- **Observed Gap in Posthaze:**
  - `submit_url_from_input()` and `paste_and_probe_from_clipboard()` ([crates/posthaze-ui/src/main.rs#L824-L857](file:///e:/Development/posthaze-download-manager/crates/posthaze-ui/src/main.rs#L824-L857)) treat the entire input/clipboard as a single URL or single `curl` command. Pasting 10 links or a `file_*.zip` pattern fails probing or only opens the last/literal string.
- **`misterdownloadmanager` Pattern:**
  - **Smart Clipboard Classifier (`clipbatch.rs`):** `clipbatch::read()` ([crates/app/src/clipbatch.rs#L34-L57](file:///C:/Users/prage/.gemini/antigravity/brain/68f916d5-a49d-44b1-b60f-1a921a1da2d5/scratch/misterdownloadmanager/crates/app/src/clipbatch.rs#L34-L57)) parses any text block (plain lines, forum posts, Markdown, HTML) for URLs:
    - Multiple URLs → opens **Link Grabber** ([crates/app/src/grabber.rs#L1-L250](file:///C:/Users/prage/.gemini/antigravity/brain/68f916d5-a49d-44b1-b60f-1a921a1da2d5/scratch/misterdownloadmanager/crates/app/src/grabber.rs#L1-L250)), deduplicated, grouped by page or split-archive volume (`movie.part1.rar`, `movie.7z.001`), with concurrent `HEAD` checks (`8` total / `4` per host) to resolve real names/sizes and filter out HTML pages (`web_page()`).
    - Single URL containing `*` or a filename number (`<= 6` digits, ignoring `%20`, e.g., `ep01.mp4` → `ep*.mp4`, width `2`) via `numbered()` ([clipbatch.rs#L66-L121](file:///C:/Users/prage/.gemini/antigravity/brain/68f916d5-a49d-44b1-b60f-1a921a1da2d5/scratch/misterdownloadmanager/crates/app/src/clipbatch.rs#L66-L121)) → opens **Batch Download** pre-filled with `From` and focus on `To` (`batch.rs#L58-L69`).
  - **Batch Wildcard Modal (`batch.rs`):** Expands numeric ranges (with zero-padding width `1..=10`) or letter ranges (`a..=z` / `A..=Z`), capped at `100,000` URLs, with live preview of the first/second/last generated filenames ([crates/app/src/batch.rs#L84-L144, #L256-L350](file:///C:/Users/prage/.gemini/antigravity/brain/68f916d5-a49d-44b1-b60f-1a921a1da2d5/scratch/misterdownloadmanager/crates/app/src/batch.rs#L84-L144)).
- **Posthaze Recommendation:**
  - When `submit_url_from_input()` or `paste_and_probe_from_clipboard()` sees multiple `http(s)://` URLs (excluding a single `curl` command) or a single URL containing `*`, route to a lightweight **Batch / Multi-Link Intake Modal** (checklist with optional background `probe_with_headers`, folder selector, and `Add Queued` / `Start All`).

### 3.4 Expired Signed-Link Refresh ("Refresh Download Address") (`P1`)
