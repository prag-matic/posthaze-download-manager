# Comprehensive Settings, Custom Headers & Context Menu

This document summarizes the configurable `Settings`, custom HTTP header / cURL support, and download row context menu implemented across `posthaze-engine` and `posthaze-ui`.

## Comprehensive Settings (`SettingsWindow` & `SettingsModalState`)

Settings opens in its own dedicated, resizable GPUI OS window (`SettingsWindow`, `840×580` with single-instance focus reuse) accessible from the Sidebar, the TitleBar Update badge, **`Ctrl+,`**, and **Settings...** in the Windows System Tray menu (even while the main window is hidden in the tray). It uses a 6-tab left-navigation layout (`General`, `Downloads`, `Network`, `Appearance`, `Integrations`, `System`) grouped into uniform bordered section cards backed by SQLite (`0004_extended_settings.sql` through `0012_notify_on_started.sql`), with transactional **`CANCEL`** (reverting any un-applied live theme/backdrop preview), **`APPLY`** (committing settings without closing the window), and **`SAVE SETTINGS`** actions:

- **General:** Window & startup preferences (close-to-tray `ui_close_to_tray`, launch on Windows startup `launch_on_startup`) and interactive in-process Windows Toast notifications (`notify_on_added` when queued, `notify_on_started` on first transfer start, `notify_on_completed`, `notify_on_failed`, `notify_only_inactive`, showing filename, size, folder, and failure reason cleanly without spawning a console window—with click-to-open UI plus **Open File**, **Show in Folder**, and **Retry** actions).
- **Downloads:** Default save folder, file-type subfolder auto-categorization (`Archives`, `Video`, `Audio`, `Documents`, `Programs` via `categorize_subfolder`), Pre-Flight toggles (`ui_lock_file_extension`, `ui_show_add_paused`), file-exists collision policy (`CollisionPolicy::{Rename, Overwrite, Ask}`), row delete button default (`DeleteDefaultAction::{Ask, Remove, DeleteFile}`), automatic retry count (`auto_retry_count`), and disk flush durability (`sync_on_complete`).
- **Network:** Proxy routing (`ProxyMode::{System, None, Manual}`), global download speed limit (`BandwidthLimiter` with `Low` / `Medium` / `High` / `Unlimited` presets or custom KiB/s), `max_workers` (`1..32`), and `max_concurrent_downloads`.
- **Appearance:** 8 built-in theme presets in a responsive 2-column grid (5 opaque themes plus Windows 11 22H2+ `Mica (System)`, `Mica Dark`, and `Mica Light` with automatic opaque fallback), accent override swatches, table density, visible columns, scale (`90%`, `100%`, `110%`, `125%`), and main workspace chrome (`ui_click_row_opens_inspector`, `ui_start_sidebar_collapsed`, titlebar telemetry, toolbar labels, scrollbar minimap).
- **Integrations:** One-click Browser Capture Native Messaging Host registration (`com.posthaze.host`) for Chrome, Edge, and Brave—pre-filled with the extension's deterministic unpacked ID (`eiophahfcjidkfgdddgejjglglaopahi`) and invoking `posthaze-cli.exe` directly with zero `.cmd` shim—plus post-completion external command hook (`%path%` substitution) and 1-click Windows Defender (`MpCmdRun.exe`) preset.
- **System:** Application version & install mode (`INSTALLED` / `PORTABLE`), automatic update checks (`auto_check_updates`), **Check Now**, signed silent install (`INSTALL v{x}`), GitHub release notes link, **Copy Config JSON**, **Open Logs Folder**, **Clear Recent Folders** (`DownloadEngine::clear_recent_folders`), and **Restore Defaults** (`Settings::default()`).

## Custom Headers & Paste as cURL

- `DownloadEngine::probe_with_headers` and `DownloadRequest.headers` persist custom request headers (`Cookie`, `Referer`, `User-Agent`) in SQLite (`0003_request_headers.sql`) so pause and resume preserve session context.
- `posthaze-ui` (`curl_parser.rs`) parses both plain URLs and Browser DevTools *Copy as cURL* commands (Bash and Windows `cmd` `^"` syntax) in the URL bar and **Paste & Probe**.

## Download Row Context Menu & File Operations

Right-clicking a download row opens `context_menu.rs` with state-aware transfer controls (`Pause`, `Resume`, `Restart Fresh` / `Download Again`, `Cancel Transfer`), file/link actions (`Open File`, `Show in Folder`, `Copy URL`, `Inspect Byte-Map`), `Completed`-file operations (`Verify Checksum / Integrity`, `Rename File...`, `Move To...` backed by `DownloadEngine::compute_file_checksums`, `rename_completed_file`, and `move_completed_file`), and explicit `Remove from List`, `Move File to Recycle Bin`, and `Delete Permanently (Shift+Del)` actions:

- **Multi-Algorithm Checksum Verification (`Verify Checksum / Integrity`):** Computes `BLAKE3`, `SHA-256`, `SHA-512`, `SHA-1`, `MD5`, and `CRC32` in a single sequential pass (`FileChecksums`), displays copyable rows for every algorithm, and includes a **Paste Expected Digest** input (`PASTE` button or keyboard paste) supporting raw hex, Base64 (`Content-MD5` / RFC 9530 `Repr-Digest` `sha-256=:...:`), or `algo:hash` strings with instant `MATCH` / `MISMATCH` verification feedback.
- **Recycle Bin vs. Permanent Deletion:** Under **Settings → Downloads → Remove Button Action**, selecting **Recycle Bin** moves deleted completed files to the **Windows Recycle Bin** (`FOF_ALLOWUNDO`) by default, while **Ask Each Time** opens a confirmation modal with an interactive **Keep on Disk** / **Recycle Bin** / **Permanent** selector whenever a completed file exists on disk. Holding **`Shift+Delete`** (keyboard) or **`Shift+Click`** on any Trash/Delete button—or choosing **`Delete Permanently (Shift+Del)`** in the row context menu—prompts to permanently unlink both the queue record and disk file via `DeleteFileMode::Permanent`.

## Windows Shell & Power Integration

- **Active-Transfer Sleep Prevention:** While any `Download` is `Active` or `Probing`, `posthaze-ui` acquires a `PowerRequestSystemRequired` handle (`PowerCreateRequest` / `PowerSetRequest`) so Windows stays awake for background downloads (while still allowing the display to sleep), clearing it automatically when transfers pause, complete, or exit.
- **Taskbar Aggregate Progress:** Reflects combined progress of active downloads onto the Windows taskbar button via `ITaskbarList3` (`TBPF_NORMAL` with completed/total byte ratio, `TBPF_INDETERMINATE` when byte sizes are unknown or probing, and `TBPF_NOPROGRESS` when idle).
- **Actionable Failure Diagnostics:** `Failed` inspector errata strips map engine and HTTP errors (`401`, `403`, `404`, `429`, `5xx`, timeouts, DNS, TLS, range invalidation, disk space) to human-readable headlines with actionable recovery tips.
